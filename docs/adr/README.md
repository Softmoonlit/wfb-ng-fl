# docs/adr 目录说明

## 目录角色

`docs/adr/` 用于记录项目已经做出的关键架构决策，以及这些决策背后的背景、权衡与边界。

## 如何使用

- 先读 `docs/README.md` 确认当前总体文档入口
- 当你遇到“为什么要这样设计”时，再回到对应 ADR 查决策背景
- 如果某个建议与现有 ADR 冲突，应显式指出，而不是静默覆盖

## 编号与含义

- 文件名以编号开头，例如 `0006-...md`
- 编号越大，不一定代表优先级更高，只代表记录顺序
- 文件名中的主题用于快速定位决策主题
