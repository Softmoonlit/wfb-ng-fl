## 目标设计与当前运行路径

当前真实硬件 Runtime 正式入口是[Issue #41 SSH 编排验收手册](../../tests/fl_runtime/v8_issue41_SSH编排真实硬件FL闭环验收手册.md)及其 `issue41_fl_runtime_loop.sh run-all`；ARMv8 现场文件传输演示从[操作手册](../ARMv8集群部署与演示操作手册.md)进入。二者使用 SSH 管理平面，不能据此宣称 0012 的无 SSH 常驻双守护、带内热发现和射频重配已经落地。

现行设计、[部署与运行基准](../部署与运行基准.md)和[v6 硬件验收细则](../v6第一版正式验收标准细则.md)分别负责规范、运行与证据边界。ADR 的历史参数和阶段验收建议不覆盖这些文件。
