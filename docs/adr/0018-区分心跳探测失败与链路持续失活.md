# 区分单次心跳探测失败与链路持续失活

fl04 在 149/HT40+/14 档基线上完成单客户端双向传输，但常驻心跳仍反复失稳。单独提高 fl04 功率至18档、以及将空口 READY/GRANT 固定MCS0都没有消除故障。MCS0四端对照中，fl04在心跳年龄10.63秒时被Server投影为OFFLINE，当时客户端仍申报IDLE，之后才进入HUNTING；fl01/fl02在同窗口保持READY。证据见 `.scratch/real-fedavg-training/evidence/08-jetson-preflight/heartbeat-149/control-mcs0/README.md`。原空闲约5秒一次、Server静默10秒即离线的组合，使单包丢失与正常排队即可触发离线；客户端连续两次230ms探测失败就换频，则会放大恢复间断。

空闲心跳默认改为约2秒一次，与活动心跳的默认周期一致。230ms继续是一次请求的硬等待预算；连续探测失败只记账，不直接认定链路失活。客户端在IDLE且不处于射频切换事务时，仅当自最近一次有效ACK对应请求的本机单调发送时间起，连续至少10秒没有新的有效确认，才进入HUNTING。成功寻频建立这一活性锚，后续成功请求推进它；不以迟到回执的接收时间延长已消耗的预算。Server仍按自上次收到心跳起静默超过10秒投影OFFLINE。

回执继续严格归属本次请求、当前信道和配置服务端端点。旧请求、错信道、错来源回执不能刷新活性；不引入历史ACK缓存、额外接收线程或自适应门限。寻频阶段本身的探测预算、活动作业liveness、射频事务租约、native授权和FEC均保持原契约。正常短暂丢包获得多次发送机会，真正持续失联仍在原有10秒量级被发现。

拒绝仅增加miss次数或盲目放宽单次ACK超时：两者仍把信道探测的短等待与端到端活性混为一谈。隔离测试必须覆盖丢一两次包但静默不足10秒时保持IDLE、持续失联到边界后进入HUNTING、有效确认恢复及错误回执不能续期；最终仍需统一构建四端后的持续心跳实测，单测通过不等于训练或硬件验收通过。

## 九客户端实测与固定调度预算修订

2026-11-08 九客户端现场复核发现，服务端 `build_v6_uplink_server_command` 仍按 ADR-0014 省略调度参数，依赖 native 内置的 Grant 120ms / Guard 10ms。九节点全轮周转为 `9 × (120 + 10) = 1170ms`，已经超过单次 ACK 的 230ms 硬等待预算。此前六客户端大文件吞吐实验选出的长时隙，不能直接证明常驻心跳在九客户端下仍满足单次回执时限。被动诊断记录见 `evidence/heartbeat-nine-diagnosis-20261108T071757Z/REPORT.md`，其中对 230ms 单次等待与 10s 失活门限作了区分。

同一 native SHA 的现场对照仅通过 CLI 将 Grant 改为 10ms、Guard 保持 10ms，初次 `check-nine-ready` 曾返回 PASS；后续45秒捕获中fl01/fl05及时有效ACK分别为20/22、19/21且没有寻频，八台实际状态恢复，而fl04仍反复失确认，其双接收链RSSI约-82至-86，明显弱于其余节点。故此对照支持调度冲突得到缓解，不能解释为九台持续稳定或fl04故障已修复。对照采样保存在 `.scratch/fl-testbed-magazine-draft/evidence/heartbeat-nine-grant10-20261108T072355Z/`；完整九端通信和大文件吞吐仍需验收。

服务端 builder 显式输出 `--grant-duration-ms 10 --guard-interval-ms 10`，固定授权时隙与调度保护间隔，不再依赖 native 的 120/10ms 默认值。在平台最多 10 个客户端全部参与轮换时，预算为 `10 × (10 + 10) = 200ms`，相对于 230ms 单次 ACK 预算留下 30ms 给收发及处理。该计算约束固定调度周转部分，不能保证实际系统抖动、丢包及端到端处理总能在余量内完成。

本修订取代 ADR-0013 / ADR-0014 对服务端常驻守护启动路径沿用 120/10ms 的取舍：优先满足常驻控制面的单次回执预算，接受 Guard 占比由约 7.69% 增至 50%、TCP 发送窗口变短及大文件吞吐可能下降的代价，后续吞吐须以新的固定时隙重新实测。native 默认值不在本次修改范围内，不增加动态时隙或配置入口。230ms 单次等待、10s 持续失活门限以及约 2s 心跳周期均保持不变；本次通过缩短固定调度周转来适配既有预算，不延长 heartbeat 超时。

builder 回归测试直接检查真实命令中的两个显式参数、默认 1..10 节点池、200ms 最大节点数周转预算及其小于真实 ACK 常量并保留 30ms 余量的关系。
