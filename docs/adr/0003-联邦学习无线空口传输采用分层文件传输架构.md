# ADR-0003: 联邦学习无线空口传输采用分层文件传输架构

Status: accepted

为让同步联邦学习在高延迟、半双工无线空口上保持稳定闭环，同时不把链路调度细节泄漏给训练与聚合程序，项目采用五层分层架构：FL 算法层只调用 FL Runtime / SDK，Transport Backend 负责把文件交换语义映射到下行 UFTP 与每客户端独立上行会话，链路层在 TUN/IP 边界之下处理 Token、反压与反向控制窗口。之所以这样决定，是因为共享可靠会话、业务层直连传输工具、以及依赖本地 UDP 长期憋包都会把调度、重传与反压耦合错层；第一版以上行 TCP per-client 作为验证基线，必要时再切换或补充 KCP，当前现行流程与接口语义以 `docs/联邦学习系统设计入口.md` 为准，后续分阶段落地补充由 ADR-0004 与 ADR-0005 记录。

## Considered Options

- 继续保留 split-process 与本地 UDP 缓冲主线
- 让多个 client 共享一个可靠上行会话
- 让 FL 程序直接调用 UFTP、TCP/KCP 或 wfb
- 第一版直接把 KCP 作为上行基线

## Consequences

- 上层继续保留 TUN/IP 边界，不直接感知 Token
- 上行采用每客户端独立会话语义，避免多客户端共享可靠状态
- 链路层必须提供有限缓冲与可感知反压，不能把拥塞退化为静默丢包
- 第一版只以同步 FL 正常轮次闭环为主线，不在这里承诺异步 FL 或高级调度策略
- 阶段性实现可以简化内部机制，但不能破坏上述边界；具体补充由 ADR-0004、ADR-0005 记录
