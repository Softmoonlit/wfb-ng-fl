# docs 目录说明

## 目录角色

`docs/` 用于放置当前项目的设计文档、验收口径、参数迁移文档、路线图、ADR、运行基准与历史文档。

## 推荐阅读顺序

如果你想理解当前项目，请按这个顺序读：

1. 仓库根目录 `CONTEXT.md`
2. [联邦学习系统设计入口](联邦学习系统设计入口.md)
3. 按问题域读取 `design/` 下的唯一权威专题：
   - `系统分层与跨层契约.md`：五层职责、完整上下行顺序和跨层不变量
   - `FL-算法层设计.md`：训练、评估、聚合和算法调用边界
   - `FL-Runtime轮次与文件契约.md`：四个本机接口、轮次、manifest、状态机和文件契约
   - `Transport-Backend传输契约.md`：UFTP、HTTP/TCP、传输完成和失败边界
   - `链路层空口调度与反压.md`：TUN、READY/GRANT、Token Passing、队列和反压
   - `无线物理层设计.md`：monitor、raw injection、广播和射频观测能力
4. [部署与运行基准](部署与运行基准.md)：独立的部署和运维指导
5. `docs/v6第一版正式验收标准细则.md`
6. `docs/v6旧参数迁移矩阵.md`
7. `docs/后续版本路线图.md`
8. `docs/adr/README.md` 与相关 ADR

旧路径 `联邦学习无线空口传输总设计.md` 仅保留为兼容入口，不再承载设计正文。

## 子目录说明

- `design/`：六篇按问题域划分的设计专题
- `adr/`：架构决策记录
- `agents/`：agent/工程流程相关说明
- `deprecated/`：历史保留文档，不应作为当前实现依据

## 权威层级

- 设计文档集入口：`联邦学习系统设计入口.md`
- 六篇设计专题：`design/`
- 独立运行指导：`部署与运行基准.md`
- 当前正式验收细则：`v6第一版正式验收标准细则.md`
- 当前参数迁移口径：`v6旧参数迁移矩阵.md`
- 历史背景/路线图：`v5迁移基线规划.md`、`后续版本路线图.md`
- 已接受决策背景：`adr/`

设计入口和六篇专题共同拥有设计规则。验收细则、参数迁移矩阵、路线图、ADR、源码、部署文档和历史文档不能补齐设计集中的缺失语义，也不能覆盖专题中的规范性规则；它们分别承担验收、迁移、背景、实现或运行指导职责。

## 历史 / 弃用说明

本目录中有些文档是背景材料，有些是历史保留文档。不要把 `deprecated/` 里的内容当成当前实现规范。

## 下一步应该看哪里

- 看设计入口：转到 `联邦学习系统设计入口.md`
- 看 ADR：转到 `docs/adr/README.md`
- 看历史保留文档：转到 `docs/deprecated/README.md`
- 看真实硬件运行入口：转到 `tests/real_hardware/README.md`
