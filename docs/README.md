# docs 目录说明

## 目录角色

`docs/` 用于放置当前项目的设计文档、验收口径、参数迁移文档、路线图、ADR 与历史文档。

## 推荐阅读顺序

如果你想理解当前项目，请按这个顺序读：

1. 仓库根目录 `CONTEXT.md`
2. `docs/联邦学习无线空口传输总设计.md`
3. `docs/v6第一版正式验收标准细则.md`
4. `docs/v6旧参数迁移矩阵.md`
5. `docs/后续版本路线图.md`
6. `docs/adr/README.md` 与相关 ADR

## 子目录说明

- `adr/`：架构决策记录
- `agents/`：agent/工程流程相关说明
- `deprecated/`：历史保留文档，不应作为当前实现依据

## 权威层级

- 当前总体设计：`联邦学习无线空口传输总设计.md`
- 当前正式验收细则：`v6第一版正式验收标准细则.md`
- 当前参数迁移口径：`v6旧参数迁移矩阵.md`
- 历史背景/路线图：`v5迁移基线规划.md`、`后续版本路线图.md`
- 已接受决策：`adr/`

## 历史 / 弃用说明

本目录中有些文档是背景材料，有些是历史保留文档。不要把 `deprecated/` 里的内容当成当前实现规范。

## 下一步应该看哪里

- 看 ADR：转到 `docs/adr/README.md`
- 看历史保留文档：转到 `docs/deprecated/README.md`
- 看真实硬件正式入口：转到 `tests/real_hardware/README.md`
