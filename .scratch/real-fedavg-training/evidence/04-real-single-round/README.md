- `gpu-computation.txt`：启用 `WFB_RUN_MNIST_GPU_TEST=1`，计算、IDX 与模型检查 **82 passed**。实际 GPU 使用受控 IDX，完整 60,000 样本、每轮 938 次 SGD 更新，覆盖单轮及两轮计算、完整 CPU 参数制品、基础摘要、尾批次和停止。受控 1:3 权重用例检查真实加权结果及准备样本绑定。
- `client-report-radio.txt`：客户端宿主、三参入口、沙箱、审计、报告和既有无线应用检查 **105 passed**；使用公开控制入口及受控传输边界，不冒充四板无线训练。

## 核心实现

`mnist.py` 拥有训练、聚合、评估和参考准备校验；`mnist_data.py` 直接读取本机固定 IDX，严格检查结构、样本数和实际内容摘要。数据不会下载或复制入模型库，客户端训练不降级 CPU。`algorithm.py` 提供三参客户端上下文、递归只读参数和公共评估结果校验。

服务器从部署配置选择三个 callable，在可取消准备预算内冻结初始模型并完成 M0 评估；全部客户端报告通过后才发布。Coordinator 唯一推进服务端轮次，使用完整固定参与集合并保留模型、指标和独立效果结果。客户端在实际提交成功返回后报告完成；服务端等待报告后才回收资源。正式包的旧复制算法和 Runtime 仿真专用开关已删除。

## 双轴审查

以 `99865ef` 为基线分别进行 Standards 和 Spec 审查，两轴最终均无剩余可操作问题。审查中修复正式 Runtime 的只读映射支持、初始模型冻结、算法可替换边界、参数只读、评估结果及阶段约束、广播字节预算和终态 ACK 重试；专项检查与最终合并检查均通过。完整轮次期限、失联处理及控制台扩展仍按后续工单推进。
