# 04: 接入 40 MHz 真实单轮训练流程

**What to build:** 操作者选择初始模型、目标和轮数后，既有作业入口可进入真实训练流程：服务器装配算法并初始评估，全体客户端通过数据和 GPU 准备，执行本地优化、提交完整参数，服务器收齐后真实聚合、评估并安全收尾。本票先建立无无线策略的单轮路径，不设置临时的仅单轮产品限制。

**Blocked by:** 01（[生成并入库参考初始模型](01-reference-model-artifact.md)）。

**Status:** ready-for-agent

**规格依据：** [显式配置、参考计算、文件及准备契约](../spec.md#implementation-decisions)，用户故事 3～12、18～22、25。

**交付边界：** 本票交付真实算法与作业主链实现、适用的软件检查和审阅；无板时不要求证明 GPU 或无线成功，也不引入 CPU 训练降级或文件仿真替身。板端完整验证交给[Jetson 部署检查与 40 MHz 少轮试跑](08-jetson-environment-and-40mhz-trial.md)。多轮补全、完整期限／失联／停止及无线策略由对应后续工单负责。

- [ ] 通过服务器显式算法配置装配客户端、聚合和评估 callable，检查入口及配置资格；作业受理冻结配置、摘要、制品、目标、轮数和期限，各端代码预部署，不动态分发安装。
- [ ] Web 保留模型摘要、目标与轮数三个输入，默认五轮并允许少轮试跑；无需等待新的候选控件即可沿现有合法入口接入，不新增任意代码输入或算法菜单。
- [ ] Coordinator 唯一拥有服务端发布、收齐和推进，客户端入口接收 Runtime、配置及作业上下文并拥有本地循环；移除正式路径的复制训练、模板 update、复制聚合与重复服务端循环，不保留旧入口兼容分支。
- [ ] 服务器准备阶段校验初始模型与官方测试 IDX，计算初始平均损失和准确率；模型库仍不解释算法内容。
- [ ] 各端使用本地数据目录，直接检查固定官方 IDX 的结构、长度、图像／标签、计数和摘要；客户端为完整 60,000 样本、服务器为 10,000 测试样本，各客户端内容一致，不复制入库或运行时下载。
- [ ] 客户端准备阶段检查依赖、GPU 及有限设备信息，准备失败明确报告，不降级 CPU；基础角色 ready 不能替代训练准备。
- [ ] 显式上下文及宿主沿既有私有／带内控制通路传递准备和业务结果，绑定作业、节点与稳定报告身份；先验证记账再确认，支持幂等、有界重试与拒绝，不用无身份心跳 ACK 代替。
- [ ] 控制消息不超过既有 4096 字节，超限明确错误，不静默截掉身份，不通过控制通路传大清单或日志；入口导入、检查和提前退出错误不只留在本地日志。
- [ ] 全部固定参与者和服务器准备通过后才首次发布；客户端使用规格固定模型、统一预处理、SGD 参数及批大小，按实际样本统计执行每轮完整一遍训练并保留尾批次。
- [ ] 单个 update 包含 CPU 完整参数、模型格式、实际基准摘要、节点与本地轮序、样本数、优化器步数、训练损失和实际设备；Runtime manifest 不承载业务字段。
- [ ] 聚合校验完整固定集合及全部内容关联、结构、数值和统计，按实际样本数加权，原子生成新模型；异常不跳过节点、不用旧数据或半成品继续。
- [ ] 单轮形成 M0 初始评估、M1 聚合评估及产物身份，效果判据属于参考算法，执行、效果与恢复分别记录；少轮不计正式五轮验收。
- [ ] 复用原有四个 Runtime 文件接口与传输完成语义，不暴露底层对象或 Runtime 轮次身份，不由作业失败追溯撤销文件成功。
- [ ] 建立客户端提交成功返回后的明确完成报告和末轮收尾基础；构建、导入、文件格式、纯计算及可验证的控制行为按实际环境检查，记录 GPU、无线和全员恢复尚待实机。
