# 12: 完成关键故障与控制台实机检查

**What to build:** 在已部署且具有实际速率依据的集群中，用可控短作业验证真实故障、无线事务和页面状态的关键分支，形成完整可追溯记录，确认系统不会把缺失确认或异常恢复显示为成功。

**Blocked by:** 02（[勾选在线候选并整体校验目标](02-online-target-selection.md)）、07（[展示训练结果并从快照恢复作业](07-training-results-and-snapshots.md)）、08（[完成 Jetson 部署检查与 40 MHz 少轮试跑](08-jetson-environment-and-40mhz-trial.md)）、09（[标定 20 MHz 速率并交付组合表](09-20mhz-rate-calibration.md)）、10（[接入算法无线策略与轮次间重配](10-job-bound-radio-policy.md)）。

**Status:** ready-for-human

**规格依据：** [故障、页面及真实无线检查](../spec.md#testing-decisions)，用户故事 13～19、27～42、47、48。

**执行条件：** 真实设备和部署访问已具备，40 MHz 少轮试跑及组合表已通过，相关软件票已完成。用户已确认无线实现不等待硬件，因此本实机票直接依赖环境检查，不依赖其被其他软件票间接阻塞。每个既定独立处理分支至少一次，不遍历全部参数组合、不要求五轮，不恢复旧本机／namespace 回归。

- [ ] 预先列出场景、输入、预期分支、检查点和恢复办法，短作业分别记录，不计正式连续成功次数；复用同一故障状态检查 Web。
- [ ] 模型不合法、数据缺失／损坏／内容不一致及 GPU 不可用按既定检查分支明确失败，不发布首轮、不降级 CPU。
- [ ] 错误来源／轮序／基准模型、非法样本统计和非有限参数不能进入聚合，不跳过节点、套旧数据或错误显示成功。
- [ ] 实际训练异常、角色退出及心跳失联结束作业，固定集合保留，节点重新上线不恢复已失败作业。
- [ ] 准备、完整轮次和 I/O 期限分别能终止等待并收尾；计算未退出或节点未确认时保留恢复未完成，禁止冲突新作业。
- [ ] 训练中以及无线不可逆提交前后分别停止，核对请求受理、配置去向、任务退出和恢复事实；不能用固定延时或瞬时全网停止假设判通过。
- [ ] 先完成无故障双带宽短作业联调，实际交换模型和 update，核对在线更新、本机与全体目标确认、保留任务资源及下一轮门禁，不只检查 CLI 返回或缓存。
- [ ] 在真实重配中核对提交前失败恢复旧配置并保持信道；提交后确认不全保持已提交配置与 RADIO_ERROR；恢复失败及未知配置不冒充成功或强行退回 157。
- [ ] 核对事务确认集合包含受理时全部在线目标和必要待命节点，失联参与者不剔除，后上线按生效配置对齐；受控暂停不被普通失联处理错误打断。
- [ ] 通过受控场景核对旧作业、非参与者、不适用阶段、重复及冲突报告的拒绝／幂等行为；确认丢失不重复训练，过期事实不改写终态。
- [ ] 在真实页面核对在线过滤、未就绪禁选、初始空选、失效取消和恢复不重选，以及提交竞态整体拒绝；不缩减受理后固定集合。
- [ ] 核对固定参与者失联与恢复、整页重载及服务实例变化、管理状态过时、SSE／HTTP 单路可用；页面从快照恢复，不重发启动、不把管理断网当无线节点离线。
- [ ] 评估表、训练摘要、失败阶段／节点／原因、执行／效果／恢复及无线结果与实际事实一致，缺失指标或未确认恢复不显示成功。
- [ ] 保存全部尝试、各端日志与摘要、必要页面证据及实际恢复状态；失败先如实记录再修复重测，不通过删除记录或缩小范围制造通过。
- [ ] 故障检查后恢复并记录正式验收环境，交接已核对分支和限制；本票短作业不替代三次五轮或其十五轮数值复核。
