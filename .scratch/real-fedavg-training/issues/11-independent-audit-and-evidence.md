# 11: 提供独立聚合复核与持久取证流程

**What to build:** 验收执行者能从服务端实际保留的模型和 update 独立重算加权平均，取得固定容差下的报告，再将总报告、节点小型审计和服务端计算制品持久备份，支持事后重新计算。

**Blocked by:** 05（[贯通五轮模型链与末轮安全收尾](05-multiround-model-chain.md)）。

**Status:** ready-for-agent

**规格依据：** [独立数值标准与证据保留](../spec.md#testing-decisions)，用户故事 45、46、48～50。

**交付边界：** 本票完成复核／取证工具和流程、可执行的纯计算检查及审阅，不等待 GPU 或板子。可区分参数的 1∶3 输入只证明算术与工具行为，不是模拟训练。对正式三次作业全部十五轮的复核及实际持久备份，由[连续三次五轮训练与最终交付](13-three-run-final-acceptance.md)执行。

- [ ] 从服务端保留的实际模型／update 和完整性信息读取输入，核对参与集合、节点、轮序、基准关联、结构和摘要，不依赖客户端已删除沙箱或 Runtime 重启重放。
- [ ] 用独立 CPU 路径以 FP64 重算按实际 sample_count 加权的参考值，与正式 FP32 聚合输出逐张量、逐元素比较，不调用生产聚合函数或复用其求和逻辑；允许共用格式读取与校验。
- [ ] 通过条件固定为绝对差不超过 1e-6 加参考值绝对值的 1e-5 倍；结构、dtype、身份及非有限值错误直接失败，不用容差放过，也不在观察结果后放宽。
- [ ] 报告保存输入／输出摘要、节点与实际样本数、权重、精度、最大误差、逐轮结论和工具版本，可对完整作业逐轮执行。
- [ ] 用可区分参数、1∶3 样本权重直接核验正式聚合函数，并以独立结果比较，证明使用样本权重而非等权或步数；不新增数据分区或旧回归套件。
- [ ] 总报告汇集环境、冻结配置／种子、全部尝试、模型链、指标、复核、无线事务及故障／Web 结果并关联证据；无对应事实时保持缺失，不生成成功占位。
- [ ] 节点审计沿用白名单小型日志、配置、状态和 manifest，不加入客户端模型或 update 本体，不经带内控制面集中传大日志。
- [ ] 服务端初始模型、每轮全部实际 update 与聚合模型独立保存路径和摘要，不仅保留摘要或报告，足以在事后重新计算。
- [ ] 备份到操作者指定持久位置并核对摘要；复核、备份和确认之前不清理，之后由操作者显式决定原文件清理，不增加自动过期或历史数据库。
- [ ] 证据失败或不完整如实报告，不追溯撤销既有文件成功，也不把工具通过当成真实训练或最终验收通过；保留未来实机执行所需的明确输入与步骤。
