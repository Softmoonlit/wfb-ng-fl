# 07: 展示训练结果并从快照恢复作业

**What to build:** 操作者在现有作业详情中查看初始与逐轮评估、固定参与者准备和训练摘要、模型身份以及独立结果和恢复状态；页面重载或管理连接变化后依靠服务器快照恢复事实。

**Blocked by:** 04（[接入 40 MHz 真实单轮训练流程](04-real-single-round-training.md)）。

**Status:** ready-for-agent

**规格依据：** [控制台快照与最小结果呈现](../spec.md#implementation-decisions)，用户故事 24、25、37～42。

**交付边界：** 本票交付服务器快照与真实页面的完整呈现流程，可检查受控状态的显示和恢复，不等待板子。与无线／GPU 实际状态联动交给[关键故障与控制台实机检查](12-fault-and-console-hardware-acceptance.md)，真实五轮结果交给[连续三次五轮训练与最终交付](13-three-run-final-acceptance.md)。候选交互由独立工单负责，不因共享页面文件建立非必要依赖。

- [ ] 权威快照含服务实例与版本、冻结入口／配置摘要、初始制品与固定目标、轮数／阶段、模型身份和产物引用，不将服务器原始位置变成 Web 文件授权。
- [ ] 展示初始及每轮有限损失、准确率和完成事实；未取得的指标及未判定效果明确缺失／未判定，不用零或成功占位。
- [ ] 固定参与者详情保留当前在线事实、准备结果、样本数、优化器步数、训练损失及设备摘要；离线节点不从作业中删除。
- [ ] 失联、恢复上线和已有失败事实分别呈现，不推断断电或物理根因，不因重新上线恢复终态作业。
- [ ] 执行结果、效果结果、资源恢复及未确认节点分别展示；停止受理不等同资源恢复，附加错误保留阶段、节点和原因。
- [ ] 预留规格确定的有限无线事务结果呈现，尚未发生事务时按事实显示，不伪造全网生效；无线实现接入后沿同一快照契约展示。
- [ ] 刷新或同一实例重连从快照恢复当前／最近作业，不依赖事件回放或重发启动；实例变化能让选择草稿按既定规则清空。
- [ ] 管理状态过时保留最后画面并暂停启动；HTTP 轮询有效时不因 SSE 单路中断禁用，恢复后使用有效快照，不改写无线节点活性。
- [ ] 只增加最小评估表和必要摘要，有限事件辅助说明，不增加曲线、比较、历史数据库或集中大日志，不向 Runtime manifest 加页面字段。
- [ ] 完成当前环境可执行的状态序列和真实页面呈现检查，明确受控快照不是无线实测；不新增通用前端状态平台或恢复旧自动回归体系。
