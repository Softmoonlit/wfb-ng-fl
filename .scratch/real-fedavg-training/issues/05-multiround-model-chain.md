# 05: 贯通五轮模型链与末轮安全收尾

**What to build:** 已接入的真实作业能够持续进行多轮，客户端始终从本轮实际全局模型训练，服务器保存 M0～M5 的模型关联和评估，并在末轮上传已返回后结束作业，保持跨轮资源所有权清晰。

**Blocked by:** 04（[接入 40 MHz 真实单轮训练流程](04-real-single-round-training.md)）。

**Status:** ready-for-agent

**规格依据：** [轮次序列、资源所有权及参考效果](../spec.md#implementation-decisions)，用户故事 20～25、32、37、43。

**交付边界：** 本票是软件实现票，不将拿到设备作为编码和审阅的前置。跨轮 GPU／无线行为由[Jetson 部署检查与 40 MHz 少轮试跑](08-jetson-environment-and-40mhz-trial.md)先检查，再由[连续三次五轮训练与最终交付](13-three-run-final-acceptance.md)完整验收；未实测的模型改善不得填写为通过。

- [ ] Coordinator 第 k 轮发布 M(k−1)，收齐后聚合 Mk 并评估；客户端提交物绑定本轮实际读取模型的摘要和本地轮序，拒绝陈旧或错轮 update。
- [ ] 服务端始终等待受理时冻结的全部参与者，不因离线或错误自动缩减、补轮或复用旧结果；客户端正常返回不代表全局成功。
- [ ] 同一客户端算法循环、Runtime、Transport、任务接收器、任务链路及 TUN 跨轮复用；Server 持久链路跨作业保留，不逐轮关闭角色或另启空闲链路。
- [ ] 客户端每次提交成功返回后报告本地完成，再等待下一轮；报告确认只重复同一事实，不触发重复训练，且不混同上传成功或链路层 READY。
- [ ] 终态回收前取得末轮全部客户端的提交返回／完成事实，不能仅因服务器已收齐就关闭仍等待最终响应的客户端。
- [ ] 五轮保存初始及 M1～M5 的评估、模型身份和完成轮数，M5 为最终产物，不额外广播或执行末轮之后的无线策略。
- [ ] 参考任务末轮准确率高于初始、平均损失低于初始，否则如实判失败并保留已完成事实；不要求逐轮单调、固定高准确率或跨 GPU 位级一致。
- [ ] 正常回收任务角色并恢复待命，新作业创建新执行上下文，重复终态不能重启／重复复位；无线配置不隐式恢复作业初始值。
- [ ] 完成适用的多轮状态、模型关联、原子产物与末轮边界的软件检查和审阅，明确实际多轮训练／恢复由实机工单验证，不恢复旧回归体系。
