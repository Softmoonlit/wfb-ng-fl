## Answer

固定网络为 1→8→16 两层 3×3 卷积（padding 1），每层 ReLU 和 2×2 最大池化，最后 Linear 784→10 logits，共 9,098 个 FP32 参数。CPU 初始化按显式种子执行 Xavier uniform 权重和零 bias；格式为 `mnist-two-conv-fp32-v1`，只存普通字典、CPU 张量及初始化来源／种子。严格读取返回独立 CPU 模型、种子和完整 SHA-256，不改写源制品，不加载旧模板或可执行模型对象。

初始化命令、参数形状、文件约定、开发环境和可上传示例的实际路径／摘要见[使用说明](../../../docs/deployment/MNIST参考初始模型.md)。生成物通过真实本地 HTTP 模型上传接口检查入库、完整摘要、列表及重复上传去重；未将示例自动写入正在运行的生产模型库。
