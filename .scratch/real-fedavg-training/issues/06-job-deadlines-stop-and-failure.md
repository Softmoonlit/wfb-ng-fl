# 06: 落实有界等待、失联失败与停止作业

**What to build:** 真实作业在准备、训练、传输和计算阶段遇到错误、失联、期限或操作者停止时，能够停止后续推进、传递明确原因并回收资源；未退出或未确认的资源不会被报告为恢复完成。

**Blocked by:** 04（[接入 40 MHz 真实单轮训练流程](04-real-single-round-training.md)）。

**Status:** ready-for-agent

**规格依据：** [期限、停止和失败及有限控制结果](../spec.md#implementation-decisions)，用户故事 18、19、34～38。

**交付边界：** 本票完成软件路径、适用检查与审阅，不等待板子。正常少轮停止与恢复交给[Jetson 部署检查与 40 MHz 少轮试跑](08-jetson-environment-and-40mhz-trial.md)，完整故障分支交给[关键故障与控制台实机检查](12-fault-and-console-hardware-acceptance.md)。无线提交前后停止由无线策略工单接入本票既有停止机制，不扩建通用服务终止框架。

- [ ] 服务器显式配置并冻结正的准备、完整轮次、I/O 期限，区分各自覆盖范围；重试和阶段变化不无限续期，不把旧短超时当训练预算。
- [ ] 到期或停止能唤醒本层等待并显式请求下层既有取消，保持 Runtime 四接口不变；已成立文件成功不被上层终态追溯改写。
- [ ] 准备、训练、评估和聚合在合理边界协作检查停止；启动／准备等待不占满唯一控制接收线程而阻塞停止处理。
- [ ] 客户端准备与业务错误、入口导入失败、配置错误和提前退出可靠传递有限结果，绑定当前作业和节点，包含阶段、可取得轮序、稳定错误码和短原因。
- [ ] 对既有报告建立严格身份、阶段、幂等和预算处理；重复事实确认，冲突内容、旧作业或非参与者拒绝，确认丢失不重做训练。
- [ ] 固定参与者业务失败、角色异常退出或达到现有心跳失联条件导致作业失败，不缩减集合或自动续训；重新上线仅更新活性，不改写终态。
- [ ] 预留并使用受控无线事务自身的暂停／租约裁决，不让普通失联处理并发打断预期暂停；不设置全局临时标志或固定延时掩盖竞态。
- [ ] 操作者停止禁止后续轮次，复用作业绑定、有界确认与恢复结果，不能以请求受理代替全网停止或硬件断电。
- [ ] 客户端回收 RoleService 整个进程组；服务端计算未退出、传输未取消回收或待命链路未恢复时，保留未确认／失败并阻止冲突新作业。
- [ ] 独立记录执行结果、效果结果与资源恢复；首次终态不被后到消息改写，附加错误与恢复进展如实保留。
- [ ] 完成当前环境可执行的预算、拒绝、停止及状态边界检查和代码审阅；不恢复旧本机回归、namespace 验收或通用终止平台，不把未实测分支勾为实机通过。
