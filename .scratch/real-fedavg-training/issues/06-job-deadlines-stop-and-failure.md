# 06: 落实有界等待、失联失败与停止作业

**What to build:** 真实作业在准备、训练、传输和计算阶段遇到错误、失联、期限或操作者停止时，能够停止后续推进、传递明确原因并回收资源；未退出或未确认的资源不会被报告为恢复完成。

**Blocked by:** 04（[接入 40 MHz 真实单轮训练流程](04-real-single-round-training.md)）。

**Status:** resolved

**测试底座：** [fl00 + fl01、fl02、fl04 四板与已有通信基线](../spec.md#当前四板测试底座与实施进度)。票 02 已交付准备阶段期限和取消，本票在既有机制上补全训练、轮次及 I/O 边界。

**规格依据：** [期限、停止和失败及有限控制结果](../spec.md#implementation-decisions)，用户故事 18、19、34～38。

**交付边界：** 本票完成软件路径、适用检查与审阅，在当前四板执行可用的针对性验证。正常少轮停止与恢复交给[Jetson 部署检查与 40 MHz 少轮试跑](08-jetson-environment-and-40mhz-trial.md)，完整故障分支交给[关键故障与控制台实机检查](12-fault-and-console-hardware-acceptance.md)。无线提交前后停止由无线策略工单接入本票既有停止机制，不扩建通用服务终止框架。

- [x] 服务器显式配置并冻结正的准备、完整轮次、I/O 期限，区分各自覆盖范围；重试和阶段变化不无限续期，不把旧短超时当训练预算。
- [x] 到期或停止能唤醒本层等待并显式请求下层既有取消，保持 Runtime 四接口不变；已成立文件成功不被上层终态追溯改写。
- [x] 准备、训练、评估和聚合在合理边界协作检查停止；启动／准备等待不占满唯一控制接收线程而阻塞停止处理。
- [x] 客户端准备与业务错误、入口导入失败、配置错误和提前退出可靠传递有限结果，绑定当前作业和节点，包含阶段、可取得轮序、稳定错误码和短原因。
- [x] 对既有报告建立严格身份、阶段、幂等和预算处理；重复事实确认，冲突内容、旧作业或非参与者拒绝，确认丢失不重做训练。
- [x] 固定参与者业务失败、角色异常退出或达到现有心跳失联条件导致作业失败，不缩减集合或自动续训；重新上线仅更新活性，不改写终态。
- [x] 预留并使用受控无线事务自身的暂停／租约裁决，不让普通失联处理并发打断预期暂停；不设置全局临时标志或固定延时掩盖竞态。
- [x] 操作者停止禁止后续轮次，复用作业绑定、有界确认与恢复结果，不能以请求受理代替全网停止或硬件断电。
- [x] 客户端回收 RoleService 整个进程组；服务端计算未退出、传输未取消回收或待命链路未恢复时，保留未确认／失败并阻止冲突新作业。
- [x] 独立记录执行结果、效果结果与资源恢复；首次终态不被后到消息改写，附加错误与恢复进展如实保留。
- [x] 完成当前环境可执行的预算、拒绝、停止及状态边界检查和代码审阅；不恢复旧本机回归、namespace 验收或通用终止平台，不把未实测分支勾为实机通过。

## Answer

以 `d9386f9` 为基线完成软件交付。服务器在受理时冻结三项有限正数期限；作业绑定监督器以绝对轮次／I/O deadline 裁决，复用 Runtime 取消及上下文协作停止，主动监视固定参与者失联和角色故障。取消先调度客户端终态，再请求可能阻塞的下层退出；未实际退出的计算、传输和进程组不能被标为已恢复。

客户端回收异步执行，不阻塞唯一控制接收线程。新增作业绑定 `JOB_RECOVERY`／专用 ACK、稳定报告身份和恢复 epoch；本地清理完成但 ACK 未获确认时保留绑定并拒绝新任务。服务器分别记录本地退出、全员恢复和首次执行／效果结果；终态投递按冻结预算重试，部分 blocked 或一次发送异常不阻止其他参与者收到停止。受控无线租约只保留作业／事务接缝，具体策略由票 10 实施。

HTTP connect、headers、body、响应共享绝对预算，数值 TUN IPv4 避免 DNS 脱离期限；取消 shutdown socket 并等待实际退出，manifest 已成立的文件成功不被后续失败改写。Runtime 四接口保持不变。

适用 15 文件合并检查先取得 **329 passed、1 failed**，唯一旧恢复夹具迁移后，控制面／报告／无线事务四文件最终 **81 passed**；Coordinator 与上下文 **37 passed**，六实现文件类型检查、diff 检查通过。Standards、Spec 双轴最终均闭合。原始失败与修复后结果均保留，不重复累加重叠测试数。

[软件证据与范围](../evidence/06evidence/README.md)。本票没有部署或运行四板训练／故障验收；官方 MNIST 少轮训练、正常停止与恢复由 08 执行，完整真实故障分支由 12 执行。
