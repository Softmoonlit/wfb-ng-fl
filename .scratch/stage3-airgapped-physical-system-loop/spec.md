# Stage 3: 真实断网物理全流程系统闭环测试

## 阶段目标

在 Stage 2 完成协同守护引擎与常驻 Client 守护服务之后，彻底拔掉/禁用三台物理机之间的管理以太网并禁用 SSH，在纯物理无外网环境下，验证三台机器完全通过 WFB 无线空口完成多轮联邦学习仿真的全流程自治推进，验证系统的鲁棒性与防脑裂自愈能力。

## 消费 Stage 2 的核心契约与输入

1. **常驻守护架构验证**：Server 运行 `wfb-fl-server-daemon`，Client 运行 `wfb-fl-client-daemon`，开机自启无需人员登录终端；
2. **带内双平面闭环**：控制信令通过轻量对称 UDP（下行广播 9000、上行单播 9001）推进，大文件通过 UFTP 下行 + HTTP PUT 上行流式传输；
3. **射频预设与速率区间**：验证在固化 FEC 8/14 下，分别使用 `standard` 与 `robust` 预设进行 40 MiB 大载荷两轮自治推进；
4. **纯物理断网看门狗自愈演练**：在真实无线环境下人为制造节点离线或信道干扰，验证 15 秒租约式看门狗能否彻底避免信道脑裂，使全集群安全回退至基准 Channel 157；
5. **离线黑盒审计**：任务结束后通过离线收集各节点的带内日志与分源遥测，验证全生命周期无资源泄漏、无孤儿进程，状态机跃迁完全一致。
