# Stage 3: 真实断网物理全流程系统闭环测试

## 阶段目标

在 Stage 2 完成协同引擎与常驻 Client 之后，彻底拔掉/禁用三台物理机之间的管理以太网或禁用 SSH，在纯物理无外网环境下，验证三台机器完全通过空口完成多轮联邦学习仿真的全流程闭环，验证系统的自治性与鲁棒性。

## 核心验证准则

1. **绝对无外网/无 SSH**：三机物理断开管理网络，仅靠 WFB 无线空口建立连接。
2. **端到端自治推进**：
   - Server 发布任务与参数，两个 Client 自动唤醒并加入轮次；
   - 自动完成模型分发、本地模拟训练、update 提交、同步收齐与聚合；
   - 连续运行多轮后正常完成业务停止。
3. **现场黑盒可审计**：
   - 离线回收各节点日志，验证各节点状态跃迁、时间戳一致性与无丢帧假死。
