# 01: 真实硬件新拓扑 40 MiB 数据面基准摸底探路

**What to build:** 在当前三机真实硬件拓扑（Client1 USB 3.0 新网卡，Server 与 Client2 USB 2.0 网卡）下，利用现有运行门禁机制以参数化配置执行单周期 40 MiB 数据面探路（40 MiB UFTP 组播下行 + 双路 40 MiB HTTP PUT 并发上行），捕获耗时、有效吞吐与全局丢包等第一手实测基准数据，建立真实物理承载基准。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 三台机器使用最新主线代码，无线网卡处于正常工作状态。
- [ ] 参数化执行 40 MiB 单周期数据面探路，不修改核心生产代码。
- [ ] 完整记录 server 与两个 client 的传输耗时、有效吞吐与原始链路日志。
- [ ] 记录单次 I/O 进展情况，验证是否存在 120s 内无进展或卡死现象。
- [ ] 形成基准测试记录，为后续分源遥测比对与射频调优提供基准数据。
