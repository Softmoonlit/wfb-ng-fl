## 物理操作与继续入口

fl01可换入fl08网卡。fl05须先现场确认关机后再拔卡，不能因管理网不通就认定它已断电。将fl10网卡装入fl05原USB口，操作后恢复供电与管理网。

保留各端电源、位置与原USB端口；按整套网卡/天线替换记录，不据一次改善判定单独网卡芯片损坏。两块原卡标记保存，便于反向复现。

换完后先核验供体MAC、专用驱动与物理USB路径，明确更新systemd原先绑定的接口名；保持node_id/TUN/模型软件不随网卡迁移。启动后核验c665948、原生摘要、15W、GET_RADIO Long GI/40MHz、iw149/HT40/索引18，再在相同五客户端集合上抓包观察。若供电或参与集合变化须单独记录。
