## 进入选参前的阻塞项

1. **全员链路稳定性**：诊断固定候选集合的心跳／ACK 缺失，重点保留 fl07 未入网及 fl04/fl05/fl06 等寻频事实；不能只对单节点重复调参后推断全网通过。
2. **功率物理含义**：驱动负 mBm 路径对应私有 `rtw_tx_pwr_idx_override`，`iw` 负数读回可证明设置路径，但不能证明标称 dBm 或实际 EIRP。实验计划中的“下降 3 dB / 6 dB”尚不能由索引减 3 / 6 实现，需要标定或重新明确为索引限制实验；本轮未擅自更改已确认的情境定义。
3. **GI 与角色功率能力**：现行平台固定 Short GI，计划为 Long GI；功率仍全网统一，尚未实现服务端与客户端分别配置。这些能力须在通信选参前处理。
4. **9 客户端部署入口**：旧严格发布器仅支持旧四板，通用配置校验器只允许 3～7 客户端。已保存新网段九客户端候选配置 `candidate-cluster.conf`，验证因数量上限失败；未将这个不可执行配置覆盖根目录旧配置，也未调用旧地址部署入口。
5. **存储预算**：fl01 根分区可用约 1.9 GiB，fl02/fl04 约 2.2～2.3 GiB。正式模型、数据、更新和归档保留策略须在正式开测前核算；本轮未删除既有数据。
6. **正式任务入口**：尚未完成 CIFAR-10 / ResNet-18 实现、实际制品字节数及全节点训练依赖验收。该项属于正式实验准备，不用于通信配置排名。
