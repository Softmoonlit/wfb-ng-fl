## 边界

- 每个候选只执行一次，不自动重试；准入失败、射频事务失败、真实传输失败、校验失败和恢复失败分别记录。只有取得实际文件传输才形成吞吐样本。
- 固定九集合不再临时缩减。native ALL10是预分配能力池，不等于本批参与集合；不错误要求删除4号平台槽位。
- 单个候选失败后，只在独立硬件／进程／资源恢复审计通过时切到下一不同候选。管理失联、USB重置、清理失败或无法恢复时停止整个矩阵，保留现场。
- FEC切换必须所有参与链路一致冷启动，不做在线半网变更；统一source `1cd6264d5d6be660998ce60f3a349063009ecfa7`、native SHA `44d6bbf500f51df4d0b3ae8cd7a53c4a45cb55b09ca66cb5217e7ac75674feb2`。
- 切组使用不同release root保留实际启动参数与manifest，不改旧发布记录；父进程跟踪每档checkpoint与硬截止，不做无限诊断。
