# Figure 1 绘图 Agent 提示词（Prompt）

```markdown
你是一位顶级的学术论文信息图表与系统架构制图专家。请为 IEEE Communications Magazine 投稿论文绘制 Figure 1（系统架构与端到端闭环通信流程图）。请严格按照以下规格、最新视觉构图与布局要求进行矢量制图：

---

### 一、整体设计原则与硬性要求
1. **版面尺寸**：IEEE Magazine 双栏全宽跨栏图（Double-column），标准尺寸为 **宽 504 pt × 高 230~250 pt**。
2. **左上角小型架构图（Small Inset Card）**：
   - 左侧的五层架构图必须**小巧精致，固定放置在左上角**（尺寸控制在约 88 pt 宽 × 106 pt 高，绝不要占满全高）。
   - 从该小架构栈引出一条平滑的浅灰细虚线短弧，指向右侧参数服务端，表示节点内嵌。
3. **整体以图为主，文字极简**：
   - 杜绝长篇大论的文档式排版，**图元为主，文字精炼**（每处说明控制在 4~12 个字以内，仅保留核心动词与协议名）。
   - 运用丰富的矢量工程图符：服务器机架线稿、模型文件图符、天线广播波束图符、边缘计算单板机图标（带外置天线）、神经网络结构图符、轮转时隙/时钟图符。
4. **严禁直线与长箭头，全图统一使用弯曲的短箭头（Curved Short Arrows）**：
   - 严禁出现贯穿全图的长直线、折线管道！
   - 各阶段之间必须使用**平滑优美的三次贝塞尔曲线或圆弧短箭头（Smooth Curved Short Arrows）**，在空间中串联起顺时针流动的有机闭环。
5. **交付产物**：**只交付标准语义化 SVG 文件**。

---

### 二、各区域详细元素与空间布局定义

#### 1. 左上角：小型精简五层架构栈（Small Inset Card）
- 位于 `x: 8, y: 8, w: 88, h: 106`。
- 垂直紧凑堆叠，标题为 **“五层协同架构”**：
  - **联邦学习算法层**
  - **联邦学习运行层**
  - **传输适配层 (UFTP/TCP)**
  - **TUN 虚拟网卡边界**（横向细虚线分割线，中间带白色小标签）
  - **链路控制层 (调度/反压)**
  - **无线收发层 (注入/捕获)**
  - 侧面微型旁路短虚线直通物理层，标注“控制旁路”。
  - 底部微注：“节点内嵌全栈协同”。
  - 侧向引申：从右侧引出一条向右下弯曲的浅灰短虚弧线指向服务端，标注“节点内嵌”。

#### 2. 主体时序流：中央偏左为 Server，右侧为 Clients，四周为顺时针有机闭环

- **参数服务端（Server Node）**：
  - 位于中央偏左（`x: 138, y: 52`），绘制精美的机架服务器矢量线稿（包含刀片服务器插槽、蓝/绿 LED 状态指示灯），下方标注 **“参数服务端”**。

- **① 准备全局模型（步骤 ①）**：
  - 从 Server 顶部引出一条**向右上轻柔弯曲的短弧线**，带有带圈深蓝白字数字 ①。
  - 指向右侧的小型“全局模型与清单”文件图符卡片。

- **② UFTP 下行可靠广播（步骤 ②）**：
  - 从模型文件卡片向右引出一条**平滑弯曲短弧线**（带圈数字 ②），流入中上方的 **UFTP 广播卡片**（内置天线发射图符，标注 **“UFTP 下行可靠广播”** 与微注 **“原始帧高阶注入 | FEC”**）。
  - **扇出短弧线群**：从 UFTP 广播卡片右端引出一条短弧线到达中继分发点，随后平滑扇出三条轻巧的**弯曲短弧线**，分别直接指向 Client 1、Client 2、Client 3。严禁长线贯穿！

- **右侧边缘客户端集群（Clients）**：
  - 垂直排列在右侧（`x: 424`），绘制精细的单板机线稿（带 Wi-Fi 外置偶极子天线及网口）：
    - **客户端 1**
    - **客户端 2**
    - **客户端 3**
  - 在客户端 3 下方绘制垂直排列的 **3 个实心圆点省略号**，并在下方标注 **“客户端 ··· N”**，明确表示节点可扩展。

- **③ 独立校验解耦（步骤 ③）**：
  - 紧贴 Client 1 下方的浅蓝色小徽章卡片，标注 **“校验即刻启动训练\n【解耦不等待其余】”**（带圈数字 ③），一条极短弧线从下行流指入。

- **④ 本地模型训练（步骤 ④）**：
  - 从客户端节点下方引出一条**向左下弯曲的柔和短弧线**（带圈数字 ④），流入中下方的 **本地训练卡片**（内置简易神经网络拓扑图符，标注 **“本地模型训练”** 与微注 **“私有数据并行计算”**）。

- **⑤ 轮转调度有序交替回传（步骤 ⑤）**：
  - 从本地训练卡片向左引出一条**平滑水平向左的短弧线**（带圈数字 ⑤），流入 **有序回传卡片**（内置轮转时隙/时钟图符，标注 **“轮转调度有序回传”** 与微注 **“HTTP PUT / TCP 跨窗口”**）。
  - **反向 TCP ACK 辅助流**：在回传卡片上方设置一条轻柔的灰色短弯曲虚线，标注 **“反向 TCP ACK (维持流控)”**。

- **⑥ 越过屏障与全局聚合（步骤 ⑥）**：
  - 从有序回传卡片向左上方引出一条**优美的弯曲短弧线**（带圈数字 ⑥），流入置于 Server 下方的 **聚合卡片**（标注 **“越过下行屏障\n收齐更新与全局聚合”**）。
  - **闭环短弧线**：从聚合卡片顶部引出一条**向上弯曲的短弧线**直接闭环回连至 Server 底部，形成完美的顺时针流动回环。

### 三、色彩体系规范（IEEE 严谨蓝灰工程风）
- **深墨蓝（#1A365D）**：用于核心大标题、带圈步骤序号底色、关键框线。
- **主冷蓝（#2B6CB0）**：用于顺时针主通信流曲线、天线波束、关键高亮。
- **浅冰蓝（#EBF8FF / #EDF3FA）**：用于解耦卡片底色、服务器/聚合卡片浅色底。
- **炭深灰（#2D3748）**：核心说明文字。
- **中冷灰（#718096 / #CBD5E0）**：边框线、辅助虚线、微注副标。
- **字体规范**：西文 Helvetica / Arial，中文思源黑体（Source Han Sans 或 Noto Sans CJK SC）。

- **只交付单一 SVG 文件**。
- 尺寸精准为宽 504 pt × 高 230~250 pt，viewBox 铺满。
- 结构语义化，纯矢量，无冗余图层与长直管道线条。
```
