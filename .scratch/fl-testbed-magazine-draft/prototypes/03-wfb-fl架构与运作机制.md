# 第 3 节 WFB-FL 跨层体系架构与端到端运作机制

WFB-FL 把第 2 节的平台定位落实到联邦学习程序与消费级 802.11 网卡之间。实验者可以设定无线条件，从独立接收端检查实际传输；训练代码仍只处理模型和轮次。无线链路由此进入实验流程，普通网卡降低了使用门槛。

### 五层跨层体系架构

系统自上而下分为联邦学习算法层、联邦学习运行层、传输适配层、链路控制层和无线收发层。请求向下，结果和错误逐层返回。各层各有完成条件，操作启动只是过程状态。

联邦学习算法层负责训练、评估和聚合，通过本地接口交换模型与训练结果。联邦学习运行层开轮时冻结参与客户端集合，用它约束模型下发对象和最终收齐结果。算法代码无须理解底层发送机会。

传输适配层把文件交换映射到网络传输。下行使用一对多文件分发协议 UFTP 向多个客户端发送一份模型，上行由各客户端通过 HTTP/TCP 提交训练结果。链路控制层在 TUN 虚拟网络设备之下管理数据、控制消息、发送机会、有限队列、前向纠错与接收重组。无线收发层提供 monitor 模式接收、原始帧注入、广播承载和射频观测。收发结果可供检查。文件完成由传输适配层判断。

### 无线收发控制与独立观测

实验者可以设定六项无线参数，包括信道或频段、带宽、调制编码方案 MCS、保护间隔 GI、前向纠错 FEC 和发射功率。MCS 规定调制与编码档位，GI 是符号间的保护时间，链路层 FEC 用冗余片段恢复缺失数据。发送端通过原始帧注入发出按 MCS、GI 和带宽构造的 802.11 帧；信道与发射功率由网卡配置。支持范围取决于网卡和驱动，实际边界需要硬件核验。

出站队列水位和 Token 调度窗口属于链路层的运行机制。链路控制层根据积压维护水位，达到阈值便停读 TUN，积压下降后恢复读取并形成反压。Token 调度窗口是一段有截止时间的发送机会。服务端按运行中的活跃队列分配并约束这些机会。客户端到期停发，余下数据等待下一次分配。二者不属于实验者设定的六项无线参数。

独立接收端 RX_ANT 以 802.11 monitor 模式记录实际收到的无线帧及其元数据，再解析 Radiotap 头部。Radiotap 是驱动附在帧前的收发元数据头。结构化日志保留时间戳、频率、MCS、带宽和信号强度，研究者可以据此核对发送设定与实际捕获的帧。接收记录只说明独立接收端看到了什么，不能代替文件完整性判断。

### 端到端 FL 轮次全生命周期

一轮同步 FL 从服务端准备全局模型开始。联邦学习运行层冻结参与客户端集合，传输适配层通过 UFTP 高速广播模型文件及其完整性信息。需要反馈时，链路控制层按配置周期暂停主发送并安排反向控制窗口，客户端回传缺块或完成状态，UFTP 据此补发。客户端完整接收并校验模型后即可训练，无须等待其他客户端同时起跑。服务端确认全部目标的模型文件完整交付后，才越过下行完成屏障。

本地训练结束后，客户端生成训练结果并发起提交。连接或数据使出站队列从空变为非空时，链路层发送上行就绪声明。服务端验证声明，将客户端纳入活跃队列，再通过 Token 调度逐一发放发送机会。客户端获准后继续 HTTP/TCP 上传；机会到期只暂停无线发送，连接与剩余数据保留到下一次机会，因此一个大文件可以跨多个窗口完成。

服务端逐一接收训练结果，核对长度与完整性，并以元数据文件最后原子落位作为完整提交边界。下行完成屏障已经越过，且本轮全部有效结果收齐后，联邦学习运行层才向算法层返回完整集合，由算法层执行模型聚合。

上述架构把无线控制、独立观测和完整 FL 轮次接进同一条实验流程。它们能否在真实硬件上按设定生效，并产生可重复的链路与轮次结果，需要下一节通过递进的系统实验检验。
