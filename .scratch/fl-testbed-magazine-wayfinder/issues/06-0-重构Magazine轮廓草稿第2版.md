## Question

在工单 06 已产出第一版连续通读的中文 Magazine 轮廓草稿的基础上，根据最新的结构调整与叙事优化需求，撰写工单 06 及其对应 prototype 的第二个版本：

1. **第 2 节表格与叙事重构（具体物理平台对比）**：
   - 将原先的文献书目对比表改为具体无线实验平台的能力矩阵对比；
   - 彻底移除纯软件仿真平台，聚焦实际存在的物理平台（常规 Wi-Fi、蓝牙/BLE、SDR/蜂窝平台）与本项目平台（WFB-FL）；
   - 重点对比这些传统平台所欠缺的关键能力（如闭源黑盒、广播被锁死在低速率、高昂硬件与频谱门槛、缺乏帧级射频观测等），以及本项目平台具备的对应先进能力（如消费级硬件低门槛、全栈可编程、高阶 MCS 原生物理广播、非侵入式射频观测与端到端跨层契约）；
   - 在文章前端一上来就清晰、有力地展现本平台的独特优势与创新性，牢牢吸引审稿人与读者的阅读兴趣。

2. **第 3 节与第 4 节深度合并（以平台简称命名）**：
   - 将原第 3 节（跨层架构与可编程空口）与原第 4 节（跨层契约与分层验证）合并为统一的平台介绍核心章节；
   - 本节标题直接以平台缩写 **WFB-FL** 命名，使读者一看到标题就知道本节为平台的全景式深度介绍；
   - 整合五层跨层架构（F1）、可编程空口与射频观测面（RX_ANT）、跨层传输契约与端到端轮次生命周期（F2）以及三层分层验证方法，形成逻辑紧密、一气呵成的系统叙述。

3. **图表体系与后续章节联动更新**：
   - 重构后的草稿整体调整为五节经典结构：Introduction → Testbed 需求与无线平台对比 → WFB-FL 平台介绍 → 实验证据 → 讨论与开放挑战；
   - 维护完整的 7 个图表证据链（包含第 2 节的平台对比表 Table 1 与后续 F1–F5 / T1）；
   - 为工单 06-1 提供最新的审阅基准，并将工单 06-1 的阻塞关系更新为由本工单（06-0）阻塞。

## Answer

已完成工单 06 及对应 prototype 的第二版重构，产出自包含、连续通读的第二版中文 Magazine 轮廓草稿。完整草稿保存在 [`prototypes/06-0-magazine轮廓草稿.md`](../prototypes/06-0-magazine轮廓草稿.md)。

### 重大变更与设计落实

1. **第 2 节平台对比表与前沿定位（落实需求 1）**：
   - 移除了纯数值/网络仿真平台（Amadeo 等），聚焦真实无线物理实验载体；
   - 建立了包含 **常规 Wi-Fi (AP-STA / TCP/IP)**、**蓝牙 / BLE 实验平台**、**SDR / 蜂窝测试床 (如 USRP / O-RAN)** 与 **WFB-FL** 四方的核心能力对比表（Table 1）；
   - 在“硬件成本与门槛”、“物理层/MAC层可编程性”、“FL 模型广播能力”、“射频/空口观测面”、“上行防冲突与调度”、“跨层契约与 FL 闭环”六大关键维度上，系统性剖析了传统平台的固有缺陷，直接突出了 WFB-FL“在消费级硬件上兼具全栈可编程与端到端跨层契约”的不可替代性。

2. **第 3 节深度合并与平台命名（落实需求 2）**：
   - 将原架构节与契约验证节合并为统一章节：`第 3 节 WFB-FL：跨层架构、可编程空口与分层验证`；
   - 章节标题直接以平台缩写 **WFB-FL** 命名，一目了然；
   - 形成“五层跨层架构 (F1) → 可编程空口与 RX_ANT 观测面 → 跨层契约与端到端轮次生命周期 (F2) → 分层验证方法学”的流畅叙事脉络，消除了原先两节之间的叙述割裂。

3. **五节式全文因果链定型**：
   - 全文结构更新为：
     - 第 1 节：`Introduction`（问题背景、黑盒困境、中心句、三项贡献）
     - 第 2 节：`Testbed 需求与无线平台能力对比`（四项核心需求、平台局限性分析、Table 1 能力对比表、技术对手定位）
     - 第 3 节：`WFB-FL：跨层架构、可编程空口与分层验证`（五层架构 F1、参数旋钮、RX_ANT 观测、轮次契约与异常处理 F2、三层验证）
     - 第 4 节：`Experimental Evidence`（F3 实验拓扑、T1 能力资格确认表、F4 MCS 可重复性实验 RQ1、F5 端到端 FL 跨层传播实验 RQ2）
     - 第 5 节：`Discussion and Open Challenges`（实验洞察、平台当前边界约束、三大开放挑战）

4. **工单与阻塞关系更新**：
   - 工单 06-1 的阻塞前置已由 06 切换为 **06-0**，后续逐节论点与写法校准工作将以 `prototypes/06-0-magazine轮廓草稿.md` 为直接审阅对象。
