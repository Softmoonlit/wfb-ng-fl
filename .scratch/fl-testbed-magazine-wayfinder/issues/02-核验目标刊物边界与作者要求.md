# 核验目标刊物边界与作者要求

Type: research
Status: resolved
Blocked by:

## Question

IEEE Communications Magazine 当前可核验的 scope、受众、文章类型、篇幅、图表、参考文献和写作风格要求是什么？IEEE Network 与 IEEE Internet of Things Magazine 作为备选时，哪些要求会实质改变本文路线？

## Answer

查询日期 2026-08-09。第一目标维持 IEEE Communications Magazine：联邦学习无线空口 testbed 落在通信网络、基础设施、系统实现及 AI for telecommunications 的 scope 内，但必须写成跨专业可理解的教程式系统文章，以可迁移的设计方法、真实实验和 lessons learned 为中心，而非专用算法论文或平台说明书。

按普通同行评审稿规划：最多 7 个 magazine pages、全文一切内容合计不超过 5500 词、图表合计最多 6 个、参考文献最多 15 篇；数学原则上不用，必要时最多 3 个简单且展示编号的公式；双栏提交并附作者简介。现行公开指南未给摘要独立字数上限。默认走 Open Call，成稿时可按强调面选择全年收稿的 AI and Data Science Series 或 Design and Implementation Series，二者不放宽通用格式。

IEEE Network 会要求路线更聚焦网络协议、控制、实践价值与 lessons learned，并按更紧的 4500 总词规划。IEEE Internet of Things Magazine 则要求端到端 IoT solution、实际部署、business/operational value 与部署经验；若项目仅有实验室 testbed，它不是自然备选。已关闭的 testbed/Data Sets 专题所要求的大规模平台、开放数据或底层研究已发表，不能冒充当前 Open Call 硬规则。

完整核验、规则冲突和一手来源见 `research/02-目标刊物要求.md`。
