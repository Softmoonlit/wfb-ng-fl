单作业参考 MNIST 全局模型的准确率和测试交叉熵损失两图，与原评估表使用同一 HTTP/SSE 快照。图从 M0 开始，准确率显示百分比，CSV 保留 0～1 原始值。无历史库、无服务重启恢复、无多作业比较。本轮未连接生产集群，未启动训练，未部署。

实现使用原生 SVG 和现有静态资源链路，没有新依赖。服务端只调整 Console 展示投影：每个有效有限指标独立保留；算法层评估校验、作业判定不变。已明确尝试而未取得评估的失败轮次可以显示空缺和已有原因，不推断该轮执行过评估或已产生模型。未知模型摘要保持空白。

同一快照不替换 DOM；同作业增加轮次后保留已选数据点和原有图点焦点，不抢占外部焦点。新作业替换旧结果。图点可悬停、点击、键盘聚焦和激活。
