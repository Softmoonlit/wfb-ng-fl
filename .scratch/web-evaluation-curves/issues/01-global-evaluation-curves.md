# 01：单作业全局模型评估曲线及论文导出

**Status:** ready-for-agent

**Type:** task

**规格：** [已确认范围](../spec.md)

- [ ] 复用控制台快照，在参考MNIST作业详情增加准确率和测试交叉熵损失两图，与评估表并存，横轴包含M0。
- [ ] 准确率显示百分比；缺点不补零、不跨缺口连线；支持空数据、单点、失败和停止的部分结果，不猜其他算法的指标语义。
- [ ] 支持悬停／点击查看点，刷新／重连恢复、下一作业替换；不增加跨Server重启恢复或历史数据存储。
- [ ] SVG与CSV导出来自同一快照，包含作业／轮次／模型身份、单位、原始数值及已有评估判定和原因；无适用数据不输出误导图。
- [ ] 用页面公开接缝TDD覆盖点、缺口、生命周期和导出；核对生成SVG视觉和CSV数值，执行相关页面回归。
- [ ] 双轴审查、提交；部署单独按用户授权执行，不将规格完成标为实现完成。

## Comments

用户通过grill-with-docs逐项确认：单作业实时更新、全局测试两指标、缺失断线、数据点查看、SVG／CSV论文导出、仅当前实例内恢复、MNIST语义及与评估表同源。已完成需求澄清，尚未实施。
