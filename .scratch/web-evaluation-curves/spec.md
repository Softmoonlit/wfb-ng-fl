# 单作业全局模型评估曲线

## 已确认目标

在现有 Web 作业详情中增加适合论文使用的单作业全局模型评估曲线，与评估表并存。用户已逐项确认本文件范围；本功能是此前“不增加曲线”约定的一次明确扩展。代码与验证已交付，部署状态以[实施记录](evidence/README.md)为准。

## 展示与领域语义

- 当前仅解释参考 MNIST 算法的评估契约。画服务端对全局模型的测试准确率、测试交叉熵损失两张图；不画客户端本地 `train_loss`，不计算“全局训练损失”。其他算法无适用指标时显示无适用评估数据，不猜单位；不能仅因某字段名为 accuracy 就套用 MNIST 语义。
- 横轴为通信轮次，初始模型 M0 对应0，聚合模型 Mk对应k。准确率原始值0～1仅在展示时转换为百分比；CSV保留原始值。损失保持原始数值。
- 标题使用“全局模型评估”，不把完成五轮或准确率提高解释为已收敛。真实点直线相连，不平滑，不改变既有效果判定。
- 图、表及导出使用同一权威控制台状态快照。某轮进入现有评估表时同步出现图点；不从关键事件或浏览器缓存推导临时评估。
- 缺失、非法或评估失败的指标不补零、不沿用旧值、不跨缺口连线；分别处理每个指标的缺点，保留真实轮次位置并说明快照中已有的原因。没有原因时如实标为未取得，不虚构原因。尚未完成的未来轮次不生成数据点。
- 作业失败或停止后保留已有评估点，不用执行结果、效果结果或资源恢复状态替代指标事实。

## 页面生命周期与交互

- 鼠标悬停、点击／触屏点击数据点可查看轮次、模型标识、准确数值；完整数值也可从现有评估表读取。
- 沿用当前／最近作业视图，训练中逐轮更新；同一Server实例内页面刷新或重连从快照恢复。
- 下一作业替换当前展示；Server服务重启不恢复旧图。不新增历史数据库、历史查询、多作业比较、客户端多曲线或缩放。

## 论文导出

- 提供两张图各自的SVG下载，包含作业标识、指标名、坐标名和单位；图中数据和导出时快照一致，不依赖截图或外部网络服务。
- 提供同一作业评估CSV，字段包含job_id、round_index、model_sha256、loss、accuracy、verdict、reason；指标保存原始数值，缺失留空。M0判定／原因按原始事实留空，CSV准确率不是百分数。
- 导出内容来自快照中的已取得事实；无适用数据时说明原因并禁用对应图导出。不额外下载模型或客户端大日志。
- 本次不生成跨随机种子均值、标准差或置信区间；相同种子的重复流程验证不得冒充独立统计实验。

## 实施边界

优先复用现有HTTP/SSE状态和静态资源链路，不增加独立曲线API、训练采样或算法指标。项目当前没有图表库依赖；实施时按已确认的最小交互与SVG导出需求选择呈现方式，不为未来需求建立通用图表平台。图表技术选择是实施细节，不改变本规格。

## 验证

在页面公开DOM／HTTP／SSE接缝验证：M0与逐轮点、百分比、空与单点、缺口断线、失败保留、快照刷新与重连、下一作业替换、非适用算法、SVG／CSV的单位及模型身份和缺值。原评估表、作业状态与启动／停止流程不得出现回归。论文导出需实际打开生成SVG核对文字和坐标，校对CSV数值。
