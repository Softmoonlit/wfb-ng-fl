# 02: 恢复一轮 4 MiB 严格同步确定性场景

**What to build:** 恢复原始 Issue #41 的单轮确定性 FL Runtime 严格同步场景。server 发布一个确定性 4 MiB 模型，两个 client 分别接收并校验模型；client1 立即生成 update，client2 固定延迟三秒；server 在只收到 client1 时保持等待，只有两个内容不同的 4 MiB update 全部有效到达后才返回完整有序的 `[1, 2]`。该场景同时产出可机器验证的事件、场景摘要和结论，不保留 Issue #53 的双 40 MiB 两轮路径。

**Blocked by:** External prerequisite: 三台机器已上线，当前 server 能通过 SSH 控制 client1 和 client2

**Status:** need-for-review
