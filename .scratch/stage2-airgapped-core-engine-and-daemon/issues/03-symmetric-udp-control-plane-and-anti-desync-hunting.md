# 03: 对称 UDP 控制信令平面、三级寻频自愈与两军问题防护状态机

**What to build:** 交付带内控制信令协议。服务端广播严格使用全局受限广播 `255.255.255.255:9000`（命中 C++ 底座 `is_ipv4_limited_broadcast` 分发到全部天线），客户端上行单播 `10.80.0.1:9001`；服务端回复单一布尔回执 `{"ack": true}`；客户端实现三级寻频阶梯（缓存 $\rightarrow$ 157 $\rightarrow$ 候选池，单信道重试 2 次、500ms 超时，全池 < 2s）；构筑两军防虚假就绪确认门禁（寻频发 `state="HUNTING"`，只有收到 ACK 跃迁为 `state="IDLE"` 并即刻抢跑回传后，服务端才点亮就绪绿灯）；实现动态自适应心跳频率。

**Blocked by:** 02: 客户端常驻守护进程、网卡挂起轮询自愈与 RoleService 子进程沙箱

**Status:** ready-for-agent

- [ ] 交付轻量对称 UDP 控制信令协议：服务端广播目标严格使用全局受限广播 `255.255.255.255:9000`，客户端上行采用单播 `10.80.0.1:9001`。
- [ ] 服务端收到心跳后单播回复单一布尔回执 `{"ack": true}`（< 20 字节）；若检测到客户端自身当前射频配置与服务端当前生效配置不一致，自动下发增量对齐指令。
- [ ] 客户端实现三级寻频自愈阶梯：按“本地缓存信道 $\rightarrow$ 基准信道 157 $\rightarrow$ 候选池 [149, 153, 165]”轮换探测。
- [ ] 单信道快速重试 2 次（每次等待 300ms，单信道 500~600ms 快速超时），无回执立即跳下一信道，全池 4 信道在 2 秒内极速扫完。
- [ ] 构筑两军防虚假就绪确认门禁：客户端寻频心跳携带 `state="HUNTING"`，只有收到 ACK 锁定频点并跃迁为 `state="IDLE"` 即刻抢跑回传后，服务端才点亮就绪绿灯；若仅收到 `HUNTING` 则保持“连接中”。
- [ ] 实现自适应心跳频率策略：寻频期 500ms 超时快速轮换、待命期 5s 低频保活、任务期 2s 进度保活且状态跳变 0 延时即刻抢跑。
- [ ] 自动化测试覆盖单向丢包两军场景模拟与三级寻频时序单调性验证。
