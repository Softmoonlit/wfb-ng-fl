# 核实 Jetson GPU 训练环境与依赖约束

## Question

## 部署阶段检查

下列检查移交后续部署和验收，不作为当前训练作业契约设计的阻塞条件：

- 记录实际参与节点的角色、板型、CPU 架构、RAM、OS、Jetson Linux／JetPack、Python、驱动、CUDA 与 PyTorch 版本，区分真实参与节点与仅登记在配置中的节点。
- 按实际 JetPack／CUDA 环境和官方兼容资料选取 GPU 版 PyTorch 及必要依赖；不凭空指定最新版，不添加旧版本兼容层。具体安装组合在部署时固定并记录，不由运行时隐式选择。
- 检查客户端 PyTorch 是否识别 GPU，包括 `torch.cuda.is_available()`、设备信息和实际可用显存；实际训练时记录使用设备，不能将硬件支持或安装包名称当成执行证据。
- 检查参考任务的数据预置、可用存储和运行资源是否满足要求；不扩大成通用硬件基准工程。
- 按既定参考任务执行实际训练验证，并记录软件、设备和运行证据。客户端 GPU 不可用或依赖不满足时明确拒绝启动，不静默切换 CPU 或文件复制。
