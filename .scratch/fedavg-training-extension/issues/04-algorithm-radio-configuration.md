# 定义算法可调用的无线配置接口与轮次间重配边界

## Question

服务端算法怎样在作业开始前或完整轮次之间请求改变无线配置，并获得准确的完成或失败结果，同时保持网卡和链路由守护进程统一管理？

决定支持字段、集群级与节点级作用范围、调用位置和返回语义，以及该接口怎样接入 Coordinator 的轮次边界。信道一致性和发射参数的作用范围分别处理，不把全部属性都定义成任意节点可独立修改。

核对现有重配的空闲门禁、双最终屏障、租约、客户端任务链路所有权、心跳寻频和速率约束。决定轮次间进入重配前需要确认什么、哪些运行资源需要暂停或重新配置，以及部分成功、失联和急停时如何结束作业与恢复资源。不得简单删除空闲检查或让算法直接调用 iw 来绕过所有权。

不包含传输过程中的切换、自主调参策略或未提出的 PHY 参数扩展。若现有契约之间出现冲突，明确记录并交由用户裁决，不能静默覆盖。

## Context

- [真实 FedAvg 训练规划](../map.md)已经采纳开始前与完整轮次之间调用的目标。
- 当前实现只允许空闲集群重配；服务端常驻链路与客户端任务链路生命周期不同。
- 读取无线物理层、跨层和链路专题，并核对当前 radio、control、daemon、Coordinator 调用路径。
