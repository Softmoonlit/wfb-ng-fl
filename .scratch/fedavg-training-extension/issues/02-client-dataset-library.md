# 定义客户端本地数据集库与服务器可见清单

## Question

客户端预置的数据集怎样作为可复用资产管理，服务器怎样知道某个客户端有哪些数据、版本是否一致，以及是否满足作业需要？

决定数据集的身份与版本、可用性与训练就绪的区别、本地注册与清单查询方式、作业引用和删除约束、数据缺失时的错误边界。说明同一逻辑数据集在各端保存完整副本还是允许各端不同内容，以及两者如何被清单准确表达；不要预先假定同名数据就是相同样本。

本票定义库的通用边界，参考任务的具体文件布局和加载适配在参考任务及本票共同收敛后确定。数据集划分已移出本地图，本票只管理各端预置数据的身份、可用性、加载与训练所需的样本统计，不设计区间分配或索引下发。

不包含通过 Web 上传数据集或服务器分发实际样本。复用已有内容摘要、配置和控制能力前先查实际依赖及类型，不为模仿模型库外观而复制第二套不必要的通用存储实现。

## Context

- [真实 FedAvg 训练规划](../map.md)规定先采用本地预置、服务器查询的方式。
- 当前模型库集中于服务器，客户端模型临时目录不具备持久数据集库语义。
- 本票决定本地数据集身份、可用性与样本统计基础，供真实训练和作业就绪检查使用，不以数据划分能力为前提。

## Comments

- 建图时创建，尚未领取或展开决策。
- 用户将数据划分移出本地图后，本票继续保留本地数据集库范围，不承担延期划分能力。
