# 定义真实训练作业的算法接入与跨层契约

## Question

在既有 Stage 4 Web、守护进程、Coordinator、Runtime 与 Transport 基础上，如何接入已选定的 FedAvg 训练、聚合、MNIST 本地数据和无线配置，使各层拥有明确且唯一的职责？

决定 Web 作业字段与算法配置的传递、服务端聚合注入、客户端训练入口、初始与聚合模型身份、update 内容与样本权重、训练前数据检查、轮次间重配调用、异常／超时／急停语义。清理文件仿真的复制及固定大小假设，不以兼容层保留已废弃输入路径。使用各端预置数据，明确实际训练样本数与聚合权重；不新增服务器分区、区间配置或索引下发。

检查当前分支的算法入口与 Coordinator 所有权，避免照搬其他分支的历史描述。列出现行权威设计中需要显式修改的条目和唯一所有者；不将新业务状态或数据字段随意塞入 Runtime manifest，不重建通信协议。

形成足以编写实施规格的端到端调用与文件约定，但本票不编码或设计通用插件系统。指标呈现若仍有模糊需求，记录为新待决策问题，不自行扩成实验分析工具。

## Answer

### 唯一职责与正式入口

服务端由 FL Coordinator 唯一拥有发布、全员收齐、聚合调用及多轮推进；算法负责计算和无线配置策略，Daemon 负责资源与带内协调。客户端算法入口拥有本地多轮循环。已报告的服务端循环归属冲突按用户裁决统一，旧独立 server 循环、二参数 client callable、模板 update 和复制聚合不作为真实训练兼容路径。

函数与配置的唯一设计所有者为[算法层专题](../../../docs/design/FL-算法层设计.md#显式装配与配置)：

- 服务器显式配置算法 JSON 文件，必需入口为 `client_entry`、`aggregate_entry`、`evaluate_entry`，可选 `radio_policy_entry`，另有 `algorithm_config`。代码按 `package.module:callable` 指定，各端预先部署匹配依赖，不动态传代码、安装或增加注册平台。
- 作业受理时冻结入口、参数与摘要；运行中配置变化不影响当前作业。Web 继续只提交 `model_sha256`、`target_nodes`、`rounds`，默认五轮；少轮试跑不替代五轮参考验收。
- 客户端入口接收 Runtime、配置和显式作业上下文；聚合接收当前模型、按节点索引的 update 映射和指定输出路径；评估返回有限指标及末轮效果判定；可选策略通过作业绑定同步配置调用表达意图。具体形态与上下文义务见[进程内调用约定](../../../docs/design/FL-算法层设计.md#进程内调用约定)。
- 服务端聚合／评估仍在 Daemon 内作业上下文执行，客户端入口在既有 RoleService 进程组执行；不增加独立运行器或第二套联邦学习框架。

### 数据、初始模型与训练文件

初始模型沿用受控模型库的上传和 SHA-256 选择；参考任务提供固定模型结构与记录种子的初始化工具，输出未训练模型。模型库不解释参数结构，算法在准备时严格检查。每轮模型和 update 各为单个 PyTorch 文件，保存 CPU 参数张量及必要基本类型元数据；训练时客户端将模型放到 GPU。

客户端 update 含完整本地训练后模型、基准全局模型摘要、节点与本地轮序、实际训练样本数、优化器步数、平均损失和设备记录。聚合校验全部输入的身份关联、结构、数值和统计后，按 `sample_count / sum(sample_count)` 加权，原子产生下一轮文件；不把步数当权重或跳过异常节点。算法文件及实际大小取代模板和固定长度假设，仍保留共享的显式上行大小上限。字段与校验由[初始模型与算法文件](../../../docs/design/FL-算法层设计.md#初始模型与算法文件)拥有。

每端本地配置字段为 `mnist_data_dir`，只直接读取预先解压的官方 IDX：客户端 `train-images-idx3-ubyte`／`train-labels-idx1-ubyte`，服务端 `t10k-images-idx3-ubyte`／`t10k-labels-idx1-ubyte`。检查文件结构、对应计数、图片／标签值域、样本总数和两文件摘要，各客户端训练内容须相同；不增加数据注册、格式适配、下载、复制或服务器分区。参考任务的唯一模型细节、预处理与训练参数在参考实现固定归档，不增设运行时任意结构编辑。

Runtime 四个文件接口与 manifest 继续只负责原有轮次、身份、完整性和交付语义；不新增样本数、训练指标、无线配置或 job 控制字段。参见[Runtime 四接口](../../../docs/design/FL-Runtime轮次与文件契约.md#四个本机接口)。

### 准备、期限与失败

基础资源 ready 不能代替训练就绪。客户端算法通过显式上下文报告数据、GPU 与依赖检查结果；服务器完成初始模型与测试数据检查、初始评估，并验证所有目标有限报告后，才允许首轮发布。客户端 GPU 不满足时明确失败，不降级 CPU；软件版本与实际 GPU 能力部署时检查，不编造现有环境或性能。

沿现有带内控制面传递 `TASK_READY` 准备结果、`TASK_ERROR` 错误及 `ROUND_READY` 提交返回／暂停事实，保持单条 JSON 在既有 4096 字节边界内。报告按作业、节点、逻辑报告身份去重并可靠确认，不能由无身份 heartbeat ACK 冒充；大日志和数据文件不走此通路。本机通知扩展携带有限结果，不把 stdout 变成业务协议。具体控制约定由[作业准备与有限控制结果](../../../docs/design/系统分层与跨层契约.md#作业准备与有限控制结果)拥有，实施规格据此统一报文字段。

服务器控制配置显式提供 `preparation_timeout_seconds`、`round_timeout_seconds`、`io_timeout_seconds`，分别覆盖全部准备、完整轮次和传输 I/O；轮次间无线事务有自己的期限。受理时冻结，数值按部署实测选择，不把旧短启动超时当成训练预算。超时／停止唤醒等待并禁止后续轮次，计算函数协作退出；进程内算法未退出不得宣布恢复完成。

任一固定参与者明确业务错误、异常退出或满足服务器失联条件，当前作业失败，参与集合不缩减，重新上线不自动恢复。受控重配期间由事务自身处理预期暂停与确认。执行结果、效果结果和资源恢复分别保留；不以停止请求受理、固定 join 等待或管理网连接中断证明全网已停止。唯一规则见[期限、停止和失败](../../../docs/design/系统分层与跨层契约.md#期限停止和失败)。

### 轮次与无线调用装配

模型链为 M0 初始评估，第 k 轮发布 M(k−1)、收齐并聚合得到 Mk、评估 Mk；五轮以 M5 结束，保存最终产物，不再广播或调用末轮后的无线策略。参考任务最终准确率高于初始、损失低于初始，非有限值或未改善判失败但保留已完成轮次；具体效果规则属于参考算法。

可选无线策略在初始评估后、客户端启动前，以及相邻轮次聚合／评估后调用，读取已有指标、必要摘要和当前配置，通过同步 `configure_radio(patch)` 完成或返回；没有策略则不自主调参。执行前参数拒绝可由策略处理，策略异常或已开始协调后的重配失败结束作业。

逻辑带宽字段固定为整数 `bandwidth_mhz`（20／40），底座 `channel_width` 由 Daemon 根据操作者固定信道合法派生，不能成为另一套可独立设置的真值。算法不传 `channel`，不自动换信道或降带宽；其余参数范围、在线节点确认集合、带宽＋MCS 速率联动、提交前后回退和停止语义沿用无线决议并已落实到[跨层无线边界](../../../docs/design/系统分层与跨层契约.md#算法无线配置与跨层重配边界)。同步结果明确身份、阶段、目标／未确认节点、配置是否可确认及恢复状态，未知不填缓存成功。

服务端收齐不等于客户端已收到上传成功响应。轮次间重配等待各客户端本轮提交成功返回并暂停，保留 Runtime、TUN、接收器和任务链路；最终回收同样取得末轮完成事实，避免提前终止客户端。v6 在线更新、控制／数据帧配置一致性及本机确认属于链路层，物理模式与功率设置属于物理层，后续 UFTP 操作速率属于 Transport，不让算法直接调用底层接口。

### Web 结果与交接

沿用在线列表决议的空选、状态失效取消、整体提交校验、固定参与者及快照恢复规则。最小详情增加初始与各轮评估表、算法配置摘要、模型身份、参与者准备及训练摘要；独立记录 `execution_result`、`effect_result`、`recovery_state` 及失败阶段／节点／原因。未判定不得伪造成功，离线不删除已冻结参与者。唯一设计见[控制台快照与最小结果呈现](../../../docs/design/系统分层与跨层契约.md#控制台快照与最小结果呈现)。不增加曲线分析、多作业比较或历史数据库。

已按唯一所有者同步六篇设计专题和总入口，补充术语；[ADR-0016](../../../docs/adr/0016-真实训练由Coordinator推进并显式装配算法函数.md)显式标记对旧服务端入口和固定带宽假设的演进，旧 ADR 保留历史背景，不再与目标契约并列裁决。没有改写已关闭 Stage 4 规格，也不把目标设计当成已实现能力。
