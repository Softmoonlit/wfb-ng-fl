# 验证桌面 Web 操作台的信息架构与交互

## Question

面向 1280x720 及以上桌面视口，拓扑与健康、射频准备、模型上传与选择、文件仿真作业参数、运行阶段、事件日志及常驻急停应如何组织为高效且不拥挤的操作台；通过一个可浏览的静态交互原型验证哪些内容必须同屏、哪些适合标签页或对话框，以及移动端最低可用状态？

## Answer

### 原型制品与运行方式

- 静态可交互原型实现于 `.scratch/stage4-simulation-cli-and-web-dashboard/prototype/index.html`。
- 原型遵循纯原生 HTML/CSS/JavaScript，零外部网络依赖与零构建依赖，完全支持离线打开或由本地 `python3 -m http.server 8080 --directory .scratch/stage4-simulation-cli-and-web-dashboard/prototype` 启动。
- 原型内置 3 种架构变体（`?variant=A|B|C`）平滑切换、5 种作业状态模拟（空闲/下发文件/等待update/恢复待命/急停中止）与 UFTP 越界告警弹窗。

### 视口与环境边界

- 鉴于 Server 与操作者 PC 采用单网线直连管理网（无外网、无 Wi-Fi AP、无外部交换机接入），移动端物理上无法连入管理网，**彻底裁撤移动端适配**。
- 不引入针对手机窄屏（375px~480px）的响应式折叠逻辑与保底代码；
- 操作台唯一基准视口锁定为桌面操作台（≥1280x720），并自然平铺适配至 1920x1080 桌面屏幕。

### 信息架构决策（采纳 Variant C: 常驻指挥条 + 模块化工作站）

通过原型对比与论证，确立以下同屏、分页与对话框边界：

1. **顶部 64px 常驻指挥条 (Command Bar)**：
   - 包含 Server Daemon 在线状态、当前确认射频简报（`CH157 · 12dBm · MCS3`）；
   - 集成活动作业微缩看板（当前轮次 N/M、Server 阶段、阶段耗时）；
   - 右上角高亮红底**【常驻急停 (ABORT)】**按钮：全局置顶、永不被遮挡、任意标签页均一键可达（带轻量防误触确认）。

2. **核心运行态同屏闭环（「🎯 运行监控」主页）**：
   - 作业控制看板：同步轮次推进（N/M 轮）、Server 权威阶段（准备任务 / 下发文件 / 等待 update / 恢复待命）、已完成轮数、三联时钟（总耗时 / 本轮耗时 / 阶段耗时）；空闲态无缝展示新建作业表单；
   - 目标节点健康网格：两台 Client（vm1, vm2）的粗状态、心跳时效、IP 与射频参数；
   - 最新事件切片：实时滚动最近关键事件流。
   - **闭环保证**：作业执行期间，操作员眼睛和鼠标停留在主页即可获知全流程事实，**无需进行任何页面跳转**。

3. **低频准备与重载资源分页**：
   - **📦 模型库 (Model Library)**：给 10 GiB 预算条、≤1 GiB 文件拖拽流式上传、64 位完整小写十六进制 SHA-256 摘要展示与一键复制、作业引用保护指示及删除操作提供完整的宽屏表格空间，不挤压主监控屏。
   - **📡 集群与射频 (Nodes & RF)**：提供物理网卡清单、ADR-0014 扁平射频参数表单、两阶段校验与双最终屏障交互，避免运行中误触。
   - **📋 事件日志 (Event Stream)**：提供最近 100 条操作者关键事件的完整表格与级别过滤。

4. **对话框 / 弹窗 (Modal)**：
   - **UFTP 速率越界强告警阻断确认**：当选择的 `downlink_mcs` 导致下行速率超出桌面近场安全区间（12~18 Mbps，例如选配 MCS 6 达到 30 Mbps）时，弹出阻断式黄色警告 Modal，要求显式二次确认方可提交。
   - **急停防误触确认**：点击急停弹出二次确认，确认后立即调用 `POST /api/v1/jobs/{job_id}/abort`。

## Comments

### 评审与收敛记录

- 用户确认 Server 与操作者电脑单网线物理直连，无移动端使用场景，因此废除移动端适配分支。
- 对比 Variant A（1280x720 垂直拥挤）、Variant B（状态切换视图突变）与 Variant C，最终确认 Variant C（常驻指挥条 + 运行监控同屏闭环 + 独立模型库/射频分页 + 告警 Modal）为最佳架构。
