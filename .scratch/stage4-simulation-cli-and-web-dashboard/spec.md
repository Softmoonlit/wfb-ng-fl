# Stage 4: 用户交互入口：CLI 命令行与 Web 可视化面板

## 阶段目标

在底层通信、协同引擎与纯无网物理闭环均验证无误、接口完全冻结后，在 Server 侧开发面向仿真实验操作者的用户交互控制层，提供 CLI 命令行工具与浏览器 Web 可视化面板。

## 核心功能与技术约束

1. **零冗余技术栈**：
   - 坚决拒绝引入重型 Node.js/Webpack 外部编译打包链；
   - Web 界面采用纯原生单页架构（HTML5 + 原生 CSS + Vanilla JS），通过 SSE（Server-Sent Events）向浏览器实时推送状态与日志。
2. **仿真平台功能支撑**：
   - **参数配置**：在界面/命令行上自由调整射频参数（信道、MCS、功率）、FL 训练参数（轮次、参与客户端、超时等）、初始模型路径；
   - **一键执行与急停**：启动仿真、暂停、安全急停与现场清理；
   - **实时观测**：实时拓扑展示、每个客户端的空口丢包与吞吐、轮次推进曲线与收齐日志。
