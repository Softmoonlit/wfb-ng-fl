### 4. 关键科学发现与技术演进结论
1. **静默节点移出机制（Silent Node Removal）生效确认**：
   在 `src/v6_uplink.cpp` 服务端调度主循环中正式接入 `scheduler.collect_silent_node_removals`，率先完成传输的节点在连续 2 次静默 Grant 后自动从轮询队列中剔除，释放空口时间给剩余活跃节点，彻底消除了“后发节点因前序节点霸占席位而超时”的瓶颈。
2. **防抖优先组（Grant 180 ms / Guard 15 ms）综合表现最佳**：
   - 上行总并发耗时（113.51s）和整轮总耗时（141.48s）在三组中均为最低；
   - 长尾极差（22.25s）为三组中最小，节点间完成时间更均匀，最长耗时拥有超过 8 秒的安全缓冲裕量；
   - 证明较短的 Grant（180ms）能显著降低 6 节点轮询周期等待延迟（Round-Robin Latency），加速 TCP ACK 反馈回路。
3. **保护间隔 Guard 12 ms 过于激进**：
   吞吐优先组试图通过缩减 Guard 到 12 ms 来提升信道容量，实测丢包率上升至 1.41%，总上行耗时反倒拉长至 119.37s（逼近 120s 上限），证明在真实多机异构拓扑下，15 ms 是保障空口平滑切换与防止碰撞的稳健底线。
4. **全量验收指标合规**：
   三组实验 18 次 HTTP PUT 上行全部在 120 秒限制内完成并获得 HTTP 201 Committed，正式满足 Ticket 03 结算条件。
