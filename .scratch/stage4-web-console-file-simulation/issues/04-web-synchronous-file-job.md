# 04: 通过 Web 启动同步文件仿真作业

**What to build:** 让操作者可以选择模型摘要、固定目标节点和同步轮次数量启动文件仿真作业，并通过已有 Server/Client Daemon、无线控制面和无线数据面完成多轮文件闭环。该作业跳过真实训练和聚合，只验证平台编排、文件交付和完整性。

**Blocked by:** 01（建立 Web 管理入口与可恢复状态快照）、02（通过 Web 管理内容寻址模型库）

**Status:** ready-for-agent

- [ ] 作业请求只接受存在的完整小写 SHA-256、固定目标节点集合和正整数同步轮数，并支持 Server 实例生命周期内的幂等受理。
- [ ] 请求拒绝本地模型路径、插件选择、训练/聚合参数、半异步/异步模式、未版本化写入形状和资源冲突。
- [ ] Server 仅在全部目标 Client 完成当前作业的 `TASK_READY` 后发布首轮模型，作业运行期间不依赖 SSH、管理网复制或人工补发控制消息。
- [ ] 每轮经现有 UFTP 下发模型、经现有 HTTP PUT 收取 update，校验作业/轮次/节点身份、大小和 SHA-256；全部目标节点的有效 update 收齐后才推进下一轮。
- [ ] 跨轮继续使用同一模型制品并保持摘要连续性；完成固定轮数后报告成功。
- [ ] 节点失联、超时、错轮、错节点、重复提交或摘要错误使整个作业失败，不缩减目标集合、不跳过节点、不自动补轮或续跑失败轮。
- [ ] 运行监控页面至少显示当前轮次、完成轮数、总轮数、Server 阶段和执行结果；无硬件集成测试覆盖上述同步闭环和错误门禁。
