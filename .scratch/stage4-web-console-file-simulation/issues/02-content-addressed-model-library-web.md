# 02: 通过 Web 管理内容寻址模型库

**What to build:** 让操作者可以从浏览器上传普通文件、查看 SHA-256 内容寻址的模型清单、重复上传时得到去重结果，并删除未被作业引用的模型制品。上传和模型库失败都必须留下可见且可恢复的领域结果。

**Blocked by:** 01（建立 Web 管理入口与可恢复状态快照）

**Status:** ready-for-agent

- [ ] 浏览器可以通过同源 multipart 请求上传一个模型文件，Server 流式计算完整小写 SHA-256 并返回制品摘要、展示文件名、大小、创建时间和引用状态。
- [ ] 空文件、单文件超过 1 GiB、模型库容量超过 10 GiB、Content-Length/请求格式非法、连接中断和写入失败均被拒绝或清理，不留下未登记临时文件或错误容量预留。
- [ ] 相同内容重复上传得到去重成功，不产生第二份内容副本；模型列表按约定顺序返回完整元数据。
- [ ] 未被作业引用的模型可以删除；被作业引用的模型被稳定拒绝，且原制品保持可用。
- [ ] 模型库页面可以上传、刷新清单、显示摘要和引用状态、处理错误和执行允许的删除操作。
- [ ] 单元、HTTP 集成和页面测试覆盖摘要一致性、去重、容量、失败清理和引用保护。
