# 06: 交付桌面 Web 操作台闭环

**What to build:** 让操作者在桌面操作台中从模型库进入运行监控，再进入射频准备页面，完成上传、选择模型、启动作业、观察轮次、处理告警和急停。页面在目标视口内保持一致的状态和操作门禁。

**Blocked by:** 02（通过 Web 管理内容寻址模型库）、03（通过 Web 完成扁平射频准备）、04（通过 Web 启动同步文件仿真作业）、05（实现 SSE 事件、急停与资源恢复）

**Status:** ready-for-agent

- [ ] 原生 HTML/CSS/JavaScript 操作台落地已确认的信息架构：常驻状态指挥条、急停入口、运行监控主页、模型库页面和射频页面。
- [ ] 在至少 1280x720 桌面视口中，操作者可以完成上传、选择模型、启动固定轮次作业、观察状态、射频告警确认、急停和恢复后重新启动。
- [ ] 页面操作门禁与 Server 权威状态一致：运行期间保留查看状态/事件和模型上传，冲突操作禁用并显示原因，恢复未完成时不能启动作业。
- [ ] 页面只展示真实轮次、阶段、耗时、节点粗状态、错误、事件和恢复状态，不展示虚假总进度、文件传输百分比、训练/聚合阶段或链路实时遥测。
- [ ] 浏览器自动化测试覆盖正常工作流、刷新、SSE 断线恢复、去重上传、射频越界告警、急停和恢复前禁启。
- [ ] 静态资源保持零构建、零在线依赖和同源加载；页面错误状态、空状态和管理 Web 不可用状态可被操作者理解。
