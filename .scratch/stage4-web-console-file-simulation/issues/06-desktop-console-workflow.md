# 06: 交付桌面 Web 操作台闭环

**What to build:** 让操作者在桌面操作台中从模型库进入运行监控，再进入射频准备页面，完成上传、选择模型、启动作业、观察轮次、处理告警和急停。页面在目标视口内保持一致的状态和操作门禁。

**Blocked by:** 02（通过 Web 管理内容寻址模型库）、03（通过 Web 完成扁平射频准备）、04（通过 Web 启动同步文件仿真作业）、05（实现 SSE 事件、急停与资源恢复）

**Status:** resolved

- [x] 原生 HTML/CSS/JavaScript 操作台落地已确认的信息架构：常驻状态指挥条、急停入口、运行监控主页、模型库页面和射频页面。
- [x] 在至少 1280x720 桌面视口中，操作者可以完成上传、选择模型、启动固定轮次作业、观察状态、射频告警确认、急停和恢复后重新启动。
- [x] 页面操作门禁与 Server 权威状态一致：运行期间保留查看状态/事件和模型上传，冲突操作禁用并显示原因，恢复未完成时不能启动作业。
- [x] 页面只展示真实轮次、阶段、耗时、节点粗状态、错误、事件和恢复状态，不展示虚假总进度、文件传输百分比、训练/聚合阶段或链路实时遥测。

- [x] 静态资源保持零构建、零在线依赖和同源加载；页面错误状态、空状态和管理 Web 不可用状态可被操作者理解。

## Answer

已交付桌面操作台完整闭环与 Variant C 架构落地。运行监控主页（`/`）、模型库页面（`/models`）与射频准备页面（`/radio`）统一接入顶部 60px 常驻状态指挥条（Command Bar），集成 Server 在线状态徽标、已确认射频简报、活动作业微缩看板与高亮置顶的常驻急停（ABORT）按钮。

针对 ≥1280x720 桌面基线视口，运行监控主页落地同屏全景闭环：
1. 包含新建同步文件仿真作业表单，支持从模型库下拉选择或 URL `?model=` 预选模型制品 SHA-256、配置目标 Client 集合与同步轮数；
2. 作业运行期间展示真实轮次推进（N/M 轮）、Server 权威阶段（准备任务 / 下发模型 / 等待 update / 恢复待命）、实际三联耗时时钟（作业总耗时 / 本轮耗时 / 当前阶段耗时）、节点粗状态网格与关键事件流切片；
3. 严格遵循事实性门禁：断线时暂停本地耗时推算；不展示虚假总百分比、文件传输百分比、训练/聚合阶段或实时遥测曲线；
4. 运行期间保留查看状态、事件流与模型上传，冲突操作（新建作业、应用射频、删除引用模型）禁用并显示阻塞原因；
5. 急停受理后独立呈现执行结果（aborted）与资源恢复状态（recovering），在恢复完成前（`recovery_state` 为 `recovering` 或 `blocked`）强门禁阻止创建下一作业；恢复完成待命后恢复启动能力。

静态资源保持零构建、零在线依赖、同源 `/assets/` 托管。通过 Node VM 自动化测试 `desktop_workflow_page_test.js` 与 Python 集成测试 `test_fl_desktop_workflow.py`，完整覆盖模型上传与去重、模型选择与作业启动、状态推进与断线推算暂停、射频越界强告警与风险确认、急停与恢复前禁启，以及恢复后重新启动。
