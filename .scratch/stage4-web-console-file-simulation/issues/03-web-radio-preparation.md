# 03: 通过 Web 完成扁平射频准备

**What to build:** 让操作者可以在射频页面读取当前配置、填写扁平射频参数、看到下行速率安全范围和风险告警，并在空闲集群中通过确认上下文应用配置。射频应用继续由 Server Daemon 经现有控制面协调 Client Daemon 完成。

**Blocked by:** 01（建立 Web 管理入口与可恢复状态快照）

**Status:** ready-for-agent

- [ ] 页面和 API 支持读取、校验和应用信道、发射功率、上下行 MCS 及 UFTP 下行速率等扁平参数。
- [ ] Channel 161、非法信道/功率/MCS 组合和不满足既有射频约束的配置被拒绝；页面根据下行 MCS 显示安全范围和推荐值。
- [ ] UFTP 速率越界显示阻断式强告警，并要求明确确认；普通提交不能绕过该告警。
- [ ] 校验响应生成绑定配置、状态版本和 Server 实例的确认上下文；状态变化、作业启动、节点变化、服务重启或过期会使上下文失效。
- [ ] 运行中或资源未就绪时禁止应用射频；应用过程复用既有双最终屏障、15 秒租约、commit 前回退 157 和 commit 后 `RADIO_ERROR` 语义。
- [ ] 射频页面、HTTP/API 和领域测试覆盖正常应用、非法参数、确认失效、作业冲突和失败状态恢复。
